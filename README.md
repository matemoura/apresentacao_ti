# Missão TI 2027 — MSB Medical System do Brasil

Apresentação gamificada em pixel art, feita para a área de TI da MSB
apresentar seu diagnóstico e pedido de 2027 ao Diretor Industrial.

Abra [`index.html`](index.html) para escolher entre as três versões:

| Arquivo | Versão | Estilo |
|---|---|---|
| `index-v1-classico.html` | Versão 1 — Clássica | Deck original, 12 telas, direto ao ponto |
| `index-v2-rpg.html` | Versão 2 — RPG Interativo | Robô pixel art, ficha de personagem, mapa da missão, fábrica animada |
| `index-v3-industrial.html` | Versão 3 — Industrial Pixel | Bordas grossas, sombra sólida, sprites de alta fidelidade, tipografia Pixelify Sans + Silkscreen |

Todas são páginas HTML estáticas, sem build — funcionam abrindo direto
no navegador ou publicando em qualquer host estático (GitHub Pages,
Vercel, Netlify).

## Navegação (dentro de cada versão)
- Setas do teclado, scroll do mouse ou toque para avançar/voltar
- Mapa da missão (v2 e v3): clique em qualquer fase para ir direto até ela
- Cena "vitrine x bastidores" (v2 e v3): arraste a barra para revelar os bastidores
